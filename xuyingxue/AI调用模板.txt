二、代码含义

dg-bg / dg-role / dg-player：场景背景 / 左侧许映雪立绘 / 右侧玩家剪影。
src / alt：图片的完整地址 / 图片的文字说明。
dg-name / dg-text：说话人名牌 / 当前台词。
dg-speak-role / dg-speak-player：许映雪发言并高亮 / 玩家发言并高亮。
name="dg1" / id="dg1-2" / checked：第一段对话组 / 第一段第二步 / 初始显示的步骤。
for="dg1-2"：点击该 label 后显示第一段第二步。
dg-hit / dg-restart：点击继续 / 末步延迟 1.2 秒出现的重新开始按钮。
{{user}}：玩家名占位符，由聊天宿主处理替换。
