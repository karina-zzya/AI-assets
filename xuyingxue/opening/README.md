# 许映雪 · 三页便签开场白

适用于支持 HTML/CSS 的嵌入区域，保留三页纯 CSS 翻页。

- `opening.txt`：复制全文粘贴到 HTML 区域。
- `opening.html`：同一份嵌入片段，不是独立网页。
- `assets/`：本片段使用的四张图片、标题子集字体及字体许可证。
