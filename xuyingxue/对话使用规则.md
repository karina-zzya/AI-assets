# 许映雪 · 对话与素材选择流程

生成时使用 [完整规范](./许映雪_对话区与素材外链使用规则.txt)。先从 [素材对应表](./素材内容与链接对应表.txt) 找到当前场景的条目，再把条目下完整的一行地址作为普通文本填入 img 的 src 双引号之间。完成 HTML 后，把每个属性的整个值与所选条目逐字核对。

## 一、正文与组件的安排

1. 先按当前角色卡和已发生的正文继续叙述，确认许映雪是否在场，以及当前地点、时间、服装、情绪和动作。
2. 当这些条件都有对应素材时，在正文中间插入一段组件，前后保留充分的叙述、动作和对话。其余轮次按正常文字叙述推进。
3. 一段组件表现一个连续场景，建议 3～6 步。换场景或明确换装后，另起一段组件。
4. 每步台词以 60 个中文字符以内为宜；长台词按自然停顿拆成连续步骤。场景说明与旁白写在组件前后的正文中。
5. 玩家发言步骤引用玩家已经说过的话；尚无玩家发言依据时，连续安排许映雪的台词，并把下一步选择留给玩家。
6. 许映雪的性格、称呼和关系沿用角色卡与当前对话；关系的发展由双方后续互动决定。
7. 正常聊天直接在正文中插入 HTML/CSS 组件；用户单独索取源码时，交付代码块或 TXT 中的完整 HTML 片段。

## 四、表情与动作选择

先沿用当前服装分组，再阅读第三节各条目的“素材内容”“画面动作”和“适用”。同时符合当前情绪与动作的条目，就是本步图片来源。

情绪变化时，在同一服装分组内重新选条目，将新条目的完整 src 填入本步 dg-role。写台词和描述时，以该条目列出的实际动作作为画面依据。

例如，困扰思考对应“蹙眉”，主动探问对应“好奇”；表达不满时，结合程度与动作区分“暗暗生气”“闹别扭”“严肃”“生气”。“害怕”用于实际恐惧场景。

待机、害羞、难过、哭泣、递耳机等情境，目前以文字表现。之后出现与清单相符的情绪和动作时，再使用完整双人组件。

## 五、服装与场景一致性

校服：白底蓝领、蓝袖口短袖 Polo，深蓝运动长裤，白色运动鞋。
日常装：雾蓝薄外套，奶白肩部拼接与深蓝细嵌条；奶白蓝花刺绣 T 恤；深蓝双宽褶 A 字裙；白中筒袜与蓝白运动鞋。

蓝色发带、黑色长马尾是两套立绘的共同识别点。服装选择以本节所列两套素材为准。
正文出现其他服装或现有立绘之外的动作时，继续用文字叙述；条件与现有素材相符时再插入组件。

【player-idle】

适用元素：dg-player；每一步均保留。
唯一完整 src：

在每一步保留模板中的 dg-player 图片元素、位置与尺寸，并把上方完整地址原样填入 src。该地址中的中文路径按清单原样复制。

许映雪的图片 alt 和名牌填写“许映雪”；玩家图片 alt 和玩家发言时的名牌填写 {{user}}，交给宿主进行玩家名替换。该变量的实际显示取决于宿主 HTML 通道的替换支持。

玩家图片在各步保持显示；玩家发言步骤使用玩家已经说过的话。接下来如何回应与行动，留给玩家决定。

## 九、多段编号与交互

1. 先查看当前页面已有的组件编号，为新组件选择下一个可用编号 N。例如第一段为 dg1，第二段为 dg2。
2. 本段所有 radio 的 name 统一填写 dgN；第 M 步的 id 填写 dgN-M。这样每段有独立分组，每步有全页唯一编号。
3. 每个 input.dg-s 后紧接对应 div.dg-step，沿用模板的相邻选择器显示方式。
4. 本段第一步的 input 保留 checked，后续步骤使用普通 radio input。
5. 许映雪发言时，步骤 div 使用 dg-speak-role；玩家发言时使用 dg-speak-player，亮暗表现由原 CSS 处理。
6. 非末步放置 label.dg-hit，将 for 写为本段下一步的 id；CSS 会显示“点击继续 ▸”。
7. 末步放置 label.dg-restart，将 for 写为本段第一步的 id，沿用 1.2 秒后出现的重新开始按钮。
8. 增减步骤后，从第一步依次核对 id 和 label 的 for，确认每一步都能到达下一步，最后一步能回到本段第一步。
